The Library page provides users with a clear and organized overview of all available workouts.

Each workout entry displays the following information:

- Workout name
- Primary muscle group
- Difficulty level
- A dropdown arrow for expanding additional details

When the dropdown arrow is selected, the workout expands to show a brief description and an image demonstrating the exercise.

A search feature is included at the top of the page, allowing users to quickly find specific workouts by name.

Additionally, a filter feature allows users to sort workouts by muscle group.
More details about the filtering functionality are provided in the Filter Wireframe description.
